# Handwritten Digit Recognition Using Machine Learning

## 1. Introduction

Handwritten Digit Recognition is a Machine Learning project that identifies handwritten numbers from images.

In this project, I used the MNIST dataset to train a model that recognizes digits from 0 to 9.

## 2. Project Objectives

- To learn the basics of image classification.
- To explore the MNIST dataset.
- To prepare image data for Machine Learning.
- To train a Logistic Regression model.
- To evaluate model accuracy.
- To predict handwritten digits.

## 3. Technologies Used

- Python
- Google Colab
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow/Keras

## 4. Dataset

This project uses the MNIST handwritten digit dataset. It contains 70,000 grayscale images of handwritten digits from 0 to 9.

- Training images: 60,000
- Testing images: 10,000
- Image size: 28 × 28 pixels

## 5. Algorithm Used

Logistic Regression was used to classify the handwritten digit images.

The pixel values were normalized and converted into numerical features before training the model.

## 6. Model Accuracy

The initial model achieved 92.56% accuracy. After increasing the maximum number of training iterations, the final model achieved **92.64% accuracy** on the test dataset.

## 7. Results

The model was tested using sample handwritten digit images. Actual digit labels and predicted labels were displayed to check the predictions.

## 8. Conclusion

This project helped me understand image classification, data preparation, model training, and model evaluation using Python and Machine Learning.

It was a useful learning experience for understanding how computers can recognize handwritten digits.
